# The Funniest One-Line Resignation Letter

One line that is the whole resignation letter, for make.fun's `u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947` bounty.

The letter: *"This is my two weeks' notice, condensed to one line — the job never gave me time for a second."* (94 characters)

The joke makes the one-line constraint itself the punchline: the letter is one line long because the job never gave the writer time for a second one. It reads like a real resignation — formal opening, effective complaint — and the format is the grievance. The field was empty at build time (0 submissions), so this sets the bar rather than chasing it. Against the usual "I quit, effective immediately" stock line, the second clause is what earns the laugh: it turns a deadline into a complaint about the job itself.

`main.ts` (Node 22, stdlib only) writes the letter to `/output/entry.txt`, deterministically.
